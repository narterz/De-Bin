# Quickly change the change your file format using De-Bin

![De-bin homepage](deBinImg.png)

## Over 20 file conversion capabilities. All at the click of a button.
Its simple. Drag and drop the file you want to convert, choose your conversion type, convert it, then download it.

## Accepted file types include
- csv
- xlsx
- xlsb
- pdf
- jpg
- png
- txt
- zip

## Want to view or contribute to this project?
This project can currently be viewed [Here](https://de-bin.vercel.app)

To run locally:
- Clone the monorepo
- Execute 'npm i' in the client directory terminal to download dependencies
- Run client side with 'npm run dev'
- On the server install dependencies with 'pip install -r requirements.txt'
- Run server with 'flask --app main --debug run'
